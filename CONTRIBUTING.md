# Contributing

- Keep changes scoped to the Swift package and CLI.
- Run `./scripts/check.sh` before opening a PR.
- Add or update tests when changing command parsing, model resolution, or inference behavior.
- Do not add hosted-service, billing, or app-store-only surfaces back into this repo.

By submitting a contribution, you agree that it may be distributed under the Apache-2.0 license for this project.
