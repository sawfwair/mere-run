# EmbeddingGemma 2 synthetic reference

`synthetic.json` is generated by `scripts/embeddinggemma2-synthetic-reference.py`.
It contains a two-layer synthetic encoder, deterministic input IDs and masks,
and token embeddings computed with independent scalar equations using Python's
standard library. No published model weights or external runtime are used.

The fixture exercises bidirectional local attention at inclusive distance one,
global attention with wider heads, projection-only per-layer inputs, the three
residual blocks, direct RMS weights, RoPE, the output projection, and padding.
The deterministic weight formula is shared as a fixture definition; computation
is independent of the Swift/MLX implementation. Run the script with `--check` to
verify reproducibility. This fixture does not establish released-checkpoint parity.

`media.json` is generated by `scripts/embeddinggemma2-media-reference.py` using
Transformers 5.19.0 and PyTorch on CPU in FP32. It contains deterministic synthetic
weights for two-layer Gemma 4 vision and audio towers and EmbeddingGemma 2
projectors. Vision covers axial RoPE, grouped-query attention, padding, and spatial
pooling. Audio covers clipped linears, relative chunked attention, causal
convolution, subsampling, and a partially padded final chunk. These fixtures check
runtime equations against upstream code; released-checkpoint qualification is
separate. The generator never reads or embeds published checkpoint weights.

The same generator writes `audio-frontend.json`, a 1,599-sample sine-wave mel
reference with a padded final frame. Native FFT/mel preprocessing uses FP32;
the upstream filter bank uses FP64. The absolute log-mel tolerance is 0.002,
including bins close to the 0.001 additive floor.
