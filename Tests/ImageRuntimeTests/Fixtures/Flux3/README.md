# FLUX 3 reference fixtures

Generated by `scripts/validation/flux3-klein-reference.py` using the unmodified
forward functions in BFL's pinned Apache-2.0 reference source. Only architecture
constants are reduced: width 16, two heads, one early block per mode, two shared
blocks, eight image channels, and 12 text channels. All weights are synthetic.

The Float32 and BF16 results cover absent references, two reference coordinate
groups, changed destination time, and a three-step Euler trajectory. The BF16
case tests timestep rounding and Float32 state retention. These are numerical
implementation tests, not released-checkpoint quality evidence.
