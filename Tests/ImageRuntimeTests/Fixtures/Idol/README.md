# IDOL reference fixtures

Generated by `scripts/reference-parity/export_idol_fixtures.py` using the
unmodified upstream SDK at `4702a7f00850e34b6e83a2170cc123c3e9570744`.
The miniature transformer has width 32, four latent tokens, and two blocks.
Weights are deterministic synthetic tensors; no pretrained weights are bundled.

The oracle runs CPU PyTorch 2.15.0 with the SDK's FP16 projection policy and
FP32 embeddings and norms. Expected outputs include both guided flow streams,
octree logits, Gaussian features and activations, the PLY payload, and FP32
and BF16 VAE packing. These fixtures establish component parity, not full
checkpoint output quality or cross-framework random-seed equivalence.

To regenerate, install the dependencies listed in the exporter and run:

```bash
python scripts/reference-parity/export_idol_fixtures.py \
  --source /path/to/idol-sdk --output Tests/ImageRuntimeTests/Fixtures/Idol
```

The upstream implementation is Apache-2.0 licensed. See
`Sources/MereRunCore/Resources/ModelLicenses/Idol-Code-LICENSE`.

`dino.safetensors`, `vae.safetensors`, and `encoder-results.safetensors`
come from `export_idol_encoder_fixtures.py` using transformers 5.22.1 and
diffusers 0.42.1. These fixtures exercise a two-layer gated DINOv3 tower on
rectangular images and a two-level FLUX.2 VAE in FP32 and BF16. The exporter
removes transformers' `model.` wrapper prefix to match the released DINOv3
namespace. BatchNorm buffers follow the VAE dtype before normalization.

`birefnet-tiny.safetensors` and `birefnet-results.safetensors` use the upstream
BiRefNet forward methods with reduced dimensions. The exporter changes only
constructor dimensions; shifted windows, multiscale feature fusion, deformable
ASPP, image patch injection, and gradient gates retain the upstream forwards.
FP32 and FP16 deformable-convolution outputs come from torchvision 0.29.2.
`preprocess.safetensors` contains Pillow 13.0.0 byte-level Lanczos and framing
oracles. Regenerate them with `export_birefnet_fixtures.py` and
`export_idol_preprocess_fixtures.py` in `scripts/reference-parity/`.
