# Whistle numerical fixture

`synthetic.safetensors` holds mel input, encoder cross-K/V, and logits for four
cached decoder steps. It contains no checkpoint weights. The full released model
geometry is exercised with deterministic synthetic weights: each tensor repeats
97 values `sin(i * 0.1 + sortedTensorIndex * 0.3) * 0.02`.

The independent reference uses the audio graphs from
https://huggingface.co/spaces/mrfakename/whistle-webgpu/tree/main/onnx.
Only the graph structure is used; its external quantized initializers are
replaced with FP32 tensors. No ONNX graph or runtime is shipped by mere.run.
The exporter verifies the SHA-256 of both graphs and the original checkpoint.
It requires NumPy, ONNX, and ONNX Runtime in a separate Python environment.

Download `onnx/encoder.onnx` and `onnx/decoder.onnx` from that space, and
`checkpoints/whistle.safetensors` from Cactus-Compute/whistle revision
`ca5287601bef25af26dcf2e1b2bdc0843a7c19e5`. Then run from the repository root:

```bash
python scripts/fixtures/export-whistle-reference.py \
  --checkpoint /path/to/whistle.safetensors \
  --encoder /path/to/encoder.onnx --decoder /path/to/decoder.onnx \
  --synthetic --output Tests/SpeechRuntimeTests/Fixtures/Whistle/synthetic.safetensors
```

For original-checkpoint parity, omit `--synthetic`, set `--output` to
`/path/to/parity/whistle-reference.json`, place `whistle.safetensors` alongside
it, then run `MERERUN_WHISTLE_PARITY_DIR=/path/to/parity swift test --filter Whistle`.
Synthetic tolerances are 2e-5 for cross-K/V and 2e-4 for logits; original
checkpoint tolerances are 3e-4 and 3e-3. These checks establish numerical
agreement for the supplied inputs, not transcription accuracy or performance.

For packed parity also place the pinned `whistle.cact` in that directory and run
with `--cact /path/to/parity/whistle.cact --output /path/to/parity/whistle-cq-reference.json`.
The exporter independently unpacks low-order CQ2/CQ4 indices, applies FP16 norms,
and computes Walsh-Hadamard dequantization in NumPy before replacing graph
initializers. Packed tolerances are 6e-4 for cross-K/V and 6e-3 for logits.
Metal execution is selected explicitly for the packed tests.

`cq-kernels.json` is an asset-free golden generated by
`scripts/fixtures/export-whistle-cq-kernels.py` (NumPy required). It includes
zero-norm groups, both bit widths, sparse/repeated row gathers, and layer row
slices. Its numerical tolerance is 2e-6 for matmuls and 2e-7 for row gathers.

Regenerate `Sources/AudioWhistleModel/Resources/cact-layout.json` with:

```bash
python scripts/fixtures/map-whistle-cact.py --cact /path/to/whistle.cact \
  --pack /path/to/whistle.pack --output Sources/AudioWhistleModel/Resources/cact-layout.json
```

The public space's `whistle.pack` has SHA-256
`1edf33dcf5772dad142d6f19571371f98999053a7a3b4397364bea0d8f4679d0`.
The mapping script verifies both archive hashes and byte-matches every segment;
no pack or upstream neural weights are committed.
