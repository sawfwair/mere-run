# Security policy

Don't report security issues in public issues or discussions.

Use GitHub's private vulnerability reporting for this repository. Include:

- The affected version or commit.
- Steps to reproduce the issue.
- Your assessment of the impact.
- Any proposed mitigation.

If private reporting is unavailable, contact the maintainer through a private
channel on the repository hosting platform and reference this policy.

This public repository doesn't include hosted production infrastructure,
billing systems, or private deployment automation. Keep reports focused on the
code, vendored artifacts, developer tooling, and local API and runtime surfaces
that ship here.
